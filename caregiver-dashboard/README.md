# ElderCare Caregiver Dashboard

A secure, standalone web portal for family caregivers and professional nurses to monitor elders' health, medication adherence, daily tasks, vitals, chat interactions, and real AI sentiment analytics.

The dashboard runs as a standalone responsive web application served directly by the FastAPI backend at `/dashboard/`, and can optionally be embedded inside Flutter via WebView (`caregiver_dashboard_screen.dart`).

---

## 1. Quick Start

### Start the Backend
From the project root:

```bash
cd backend
python -m uvicorn main:app --reload --port 8000
```

### Access the Caregiver Dashboard
Open your browser and navigate to:
```
http://127.0.0.1:8000/dashboard/
```

- **Register a new caregiver account**: Click "Create an account", enter your name, email, phone (optional), role, and password.
- **Log in**: Sign in with your registered email and password. Your secure JWT session is stored in browser `localStorage`.
- **Link an elder**: Click "+ Link Elder" in the header and enter the elder's 6-character linking code (e.g. `CARE-4892`) generated by the elder's app.

| `SENTIMENT_DB_PATH` | `backend/eldercare_sentiment.db` | Sentiment analytics SQLite database path |

## 3. Caregiver API Endpoints

All endpoints except `/signup` and `/login` require `Authorization: Bearer <access_token>`.

### Authentication
- `POST /api/caregiver/signup` - Register a new caregiver (returns JWT token and caregiver profile)
- `POST /api/caregiver/login` - Authenticate with email & password (returns 30-day JWT token)
- `GET /api/caregiver/me` - Retrieve current logged-in caregiver profile
- `POST /api/caregiver/logout` - Clear active session

### Elder Linking & Authorization
- `GET /api/caregiver/elders` - List **only** the elders authorized for the logged-in caregiver
- `POST /api/caregiver/link-elder` - Link an elder using their 6-character linking code (`{"caregiver_linking_code": "CARE-XXXX"}`)
- `GET /api/caregiver/elders/{elder_id}` - Retrieve details for a specific authorized elder (enforces 403 Forbidden on unlinked elders)

### Medications & Dose Logs
- `GET /api/caregiver/elders/{elder_id}/medications` - Retrieve elder's prescribed medicines
- `POST /api/caregiver/elders/{elder_id}/medications` - Add a new medication (`name`, `dosage`, `times`, `diet`)
- `GET /api/caregiver/elders/{elder_id}/medication-logs` - Retrieve adherence logs (`taken`, `missed`, `skipped`)
- `POST /api/caregiver/elders/{elder_id}/medication-logs` - Record a dose event

### Reminders & Daily Tasks
- `GET /api/caregiver/elders/{elder_id}/reminders` - Retrieve scheduled reminders
- `POST /api/caregiver/elders/{elder_id}/reminders` - Create a reminder (`title`, `time`, `type`)
- `PATCH /api/caregiver/elders/{elder_id}/reminders/{reminder_id}/toggle` - Toggle reminder completed/pending

### Health Diary & Vitals
- `GET /api/caregiver/elders/{elder_id}/health-diary` - Retrieve health observations (sleep, mood, pain, notes)
- `POST /api/caregiver/elders/{elder_id}/health-diary` - Record a daily health observation

### Conversations & Sentiment Analytics
- `GET /api/caregiver/elders/{elder_id}/conversations` - Retrieve synchronized conversation history between elder and Kunchu Copilot
- `GET /api/caregiver/elders/{elder_id}/analytics` - Retrieve real daily sentiment summary and 7-day historical trends (gracefully handles `insufficient_data`)
- `POST /api/caregiver/elders/{elder_id}/copilot-chat` - Conversational caregiver AI Copilot answering queries on medications, vitals, and mood

## 4. Embedding in Flutter (Optional)

To embed the dashboard in a Flutter app, use `caregiver_dashboard_screen.dart`:

```dart
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (_) => const CaregiverDashboardScreen(
      backendBaseUrl: 'http://10.0.2.2:8000', // Or http://127.0.0.1:8000 for iOS/desktop
    ),
  ),
);
```

The Flutter screen handles:
- Real authentication via the FastAPI backend
- Automatic session token persistence
- Native speech-to-text (`speech_to_text`) and text-to-speech (`flutter_tts`) through the `FlutterVoice` JavaScript bridge
- Browser Web Speech API fallback when accessed via standard web browsers

## 5. Security & Authorization

1. **Password Protection**: Passwords hashed with salted `bcrypt` (12 rounds).
2. **Session Security**: Authenticated sessions enforced via HMAC-SHA256 JWT tokens.
3. **Data Isolation**: Caregivers can only access health records, medications, and conversations for elders explicitly linked to them via `caregiver_elder_links`. Any attempt to access unauthorized elder records immediately returns `403 Forbidden`.
4. **Credential Stripping**: Password hashes and secret tokens are never returned in elder or caregiver API responses.
5. **Medical Disclaimers**: Sentiment analytics views prominently include informational non-clinical disclaimers.
